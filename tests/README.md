# 页面结构回归

前置条件：Node.js 18 或更新版本、npm，以及安装依赖时可访问 npm registry。
在 result 仓库根目录运行：

```sh
npm ci
npm test
```

测试使用 parse5 按 HTML 解析规则读取实际 `views/index.html`，检查唯一 h1、精确文字“实时投票结果”、标题在两侧结果前的 DOM 顺序，以及原 document title、选项、计数、百分比格式、总票数绑定和客户端脚本顺序。内存中的反例覆盖标题缺失/重复/文字错误/顺序错误/隐藏以及原绑定被破坏，不改写页面文件。

另在隔离的 Node VM 中执行未修改的 `views/app.js`，用模拟 Socket.IO 事件验证 `message` 初始化和连续 `scores` 更新后的计数、总数、原取整百分比以及背景宽度；包括零票、非零票和恢复零票。无需启动服务或数据库，不连接或改变共享投票数据。

这些是开发结构与控制器单元测试，不渲染布局、不验证真实 Angular DOM 或真实 Socket.IO 网络，也不证明部署完成。后续测试 Agent 仍需使用 Chromium 访问本卡本批真实部署，记录 URL、批次/候选或部署引用、result 提交、检查时间及浏览器版本，核对标题实际唯一性、文字、可见性、位于结果上方且不遮挡，以及同一轮稳定渲染中的计数、百分比、总数关系。对真实更新只有观察到才记录通过；不清空、重置或冻结共享数据。
