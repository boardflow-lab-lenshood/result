# 结果页结构测试

前置条件：Python 3.8 或更新版本，仅使用标准库。无需 npm 安装、数据库、运行中的服务或浏览器。在 result 仓库根目录执行：

```sh
python3 tests/test_page_structure.py
```

测试读取本次工作树中的 `views/index.html` 并解析 HTML 元素，覆盖：

- 唯一的语义 `h1`、精确文案“实时投票结果”；
- 标题与 `#choice` 位于同一居中容器，标题在票数区域之前；
- 原 document title“猫派 vs 狗派 -- Result”；
- 猫派、狗派及两侧票数、百分比绑定；
- 总票数标签与绑定，以及 Angular 初始化属性和原脚本加载顺序。

这条命令是新增结构测试，不依赖原 `npm test` 占位命令或旧 PhantomJS 产物。结构测试不执行 CSS、Angular 或 Socket.IO，不能证明页面初始化后的可见性、视觉位置或实际数据更新。

后续测试阶段须在包含本卡交付提交的真实部署上用 Chromium 检查：等待现有初始化使 body 可见，断言唯一可见 h1 的标签和精确文字，比较标题与票数区的实际边界，确认两侧选项、票数、百分比及总数显示且不被遮挡。记录部署版本/交付提交、URL、核验时间和 DOM/可见性断言。观察真实 scores 变化后核对票数、百分比、总数及标题持续唯一；未观察到变化时须明确记录未验证动态更新。不要用静态结构测试代替部署浏览器证据。
